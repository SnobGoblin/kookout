# What's New in version 1.2 (App Store Connect → version 1.2 → each language → "What's New in This Version")

Draft 17 Nov 2026, not yet approved by Christian. The menu names (Edit → Wave height) match the app's own translations.

## English

New in 1.2

• Wave height on wind spots. Turn it on under Edit → Wave height to see the wave forecast next to the wind. It's on from the start at a few open-sea spots, and riders at each spot can vote on it.

• Wave forecasts now cover the whole world, the Mediterranean included.

## Norsk bokmål (nb)

Nytt i 1.2

• Bølgehøyde på vindspoter. Slå det på under Rediger → Bølgehøyde for å se bølgevarselet ved siden av vinden. Det er på fra start på noen spoter ut mot åpent hav, og utøverne på hver spot kan stemme over det.

• Bølgevarslene dekker nå hele verden, også Middelhavet.

## Svenska (sv)

Nytt i 1.2

• Våghöjd på vindspots. Slå på det under Redigera → Våghöjd för att se vågprognosen bredvid vinden. Det är på från början på några spots mot öppet hav, och åkarna på varje spot kan rösta om det.

• Vågprognoserna täcker nu hela världen, även Medelhavet.

## Dansk (da)

Nyt i 1.2

• Bølgehøjde på vindspots. Slå det til under Rediger → Bølgehøjde for at se bølgeudsigten ved siden af vinden. Det er slået til fra start på nogle spots ud mod åbent hav, og udøverne på hvert spot kan stemme om det.

• Bølgeudsigterne dækker nu hele verden, også Middelhavet.

## Deutsch (de)

Neu in 1.2

• Wellenhöhe an Windspots. Schalte sie unter Bearbeiten → Wellenhöhe ein, um die Wellenvorhersage neben dem Wind zu sehen. An einigen Spots am offenen Meer ist sie von Anfang an an, und die Rider an jedem Spot können darüber abstimmen.

• Die Wellenvorhersagen decken jetzt die ganze Welt ab, auch das Mittelmeer.

## Français (fr)

Nouveautés de la 1.2

• Hauteur des vagues sur les spots de vent. Activez-la dans Modifier → Hauteur des vagues pour voir la prévision des vagues à côté du vent. Elle est activée d'emblée sur quelques spots face au large, et les riders de chaque spot peuvent voter.

• Les prévisions de vagues couvrent maintenant le monde entier, Méditerranée comprise.

## Español (es)

Novedades de la 1.2

• Altura de las olas en los spots de viento. Actívala en Editar → Altura de las olas para ver la previsión de olas junto al viento. Viene activada en algunos spots de mar abierto, y los riders de cada spot pueden votar.

• Las previsiones de olas cubren ahora todo el mundo, Mediterráneo incluido.
