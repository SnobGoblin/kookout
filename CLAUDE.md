# Kookout: project brief for Claude

Kookout tells wing foilers, surfers and skiers when *their* spots are good: the forecast judged against each
spot's own rules (wind directions, limits, waves, snow), with push notifications when good conditions come up
or change. Built by Christian (owner, not a programmer; learning as we go) with Claude. README.md has the
details of each part; this file is the short version plus how we work.

**Business:** an iPhone app, free at launch, later about $10/year (see Pricing below); no paid APIs until it
breaks even. The web page is free.
**Status (14 Oct 2026):** build 1 in TestFlight beta review, builds up to 10 uploaded or ready; testers
("Family plus a couple guys") start when a build is approved. Not built yet: subscription/paywall.

## The parts

| Part | Where | Notes |
|---|---|---|
| Web page | `index.html`, `rules.js`, `privacy.html` | Live at kookout.no and sternell.com/wind. Deployed by GitHub Actions (SFTP to Domeneshop) on push to main. `personvern.html` forwards to `privacy.html`. |
| Shared rules | `rules.js` | `analyse(spot, metForecast, waves, {units, waveUnit, zone, daysOff})`. Used by the web page *and* bundled into the relay, so page, app and notifications always agree. Judges on rounded numbers as shown. |
| Relay | `relay/` (Cloudflare Worker `wingfoil-relay`) | `npx wrangler deploy` from `relay/`. Endpoints in the header of `src/index.js`. D1 database `kookout` (`schema.sql`), KV `WAVES` (NOAA waves, holidays). Crons: waves every 3 h, notifications hourly. |
| iOS app | `ios/` | SwiftUI, iOS 17+, Swift 6, bundle `com.sternell.kookout`, team `5KZ7KF5NNH`. Project generated by XcodeGen from `ios/project.yml`; the `.xcodeproj` isn't in git. |
| Brand | `brand/` | Logo, icons and sounds are *generated*: `swift brand/render.swift`, `swift -O brand/swoosh.swift`, `swift -O brand/gong.swift`. Font: Archivo (OFL) in `brand/fonts/`. |

Relay files: `index.js` (forecasts, live wind, waves, holidays), `notify.js` (push via APNs), `auth.js` (Sign in
with Apple, sessions), `community.js` (community spots, edits/history, majority vote), `reports.js` (reports,
emailed through Resend). Tests: `node relay/test-notify.mjs`, `node relay/test-community.mjs`.

## Decisions already made (don't relitigate without asking)

- **Community spots:** name and position are *facts*, fixed by anyone signed in (wiki style, logged in `edits`,
  undoable, moves over 2 km refused, moving only via "Move pin"). Rules are *preferences*: each follower has their
  own; the community version is the majority from 3 active followers (directions: more than half; numbers:
  median; counts rounded). A spot becomes community-owned once followed; it disappears when nobody follows it.
- **Sharing** needs Sign in with Apple and is asked once (never on by default, never while signed out).
  Following, notifications and everything else work without an account.
- **Weekend spots:** good only on days off (weekends + public holidays of the *phone's* country, from Nager.Date),
  5 hours in a row, notifications look 5 days ahead by default.
- **Powder:** snow counted over the day and the one before (`days`, default 2), optional "sunny days only".
- **Sounds:** swoosh for good news, 3 s kung-fu gong when good conditions are gone.
- **Splash:** design D (orange eyes on near-black, small wide-spaced name). iOS shows the static launch screen
  (`SplashLaunch`), then `SplashView` moves the pupils left, right and back (~1.6 s; just a fade with Reduce Motion).
  Both images and `SplashGeometry.swift` are generated by `brand/render.swift`.
- **Accent colour:** sea blue `#1C6EA4` (light), buoy orange `#FF6B2C` (dark). Navy `#0E2A3B` for the brand.
- **Moderation by hand** for now (SQL in README); a block/hide UI waits until there are many users.
- **Languages:** en, nb, sv, da, de, fr, es. Every new app text gets translated in `Localizable.xcstrings`.
- **Pricing (decided 14 Oct 2026):** free at launch, no paywall yet; the goal is active users. The first 2,000
  users are *founding users*: at least 12 months free from when they join (the app knows the first download
  date from Apple). The real end date is not fixed yet; it lives on the relay so it can change without a new
  build, and only ever in users' favour, with plenty of warning. Once 2,000 is reached, new users pay after a
  taster (e.g. 10 good-condition notifications, not a time-based trial, since the sports are seasonal). Planned
  price: about $10/year, perhaps also a lifetime option. Family stays free via Family Sharing or offer codes
  (no homemade free-account lists; Apple's rules). Never take a promised free period away early.
- **Privacy page** (English only) must match what the app actually does. Update it with every data change.

## Handy commands

```bash
cd ios && xcodegen          # after adding files or changing project.yml
xcodebuild -project Kookout.xcodeproj -scheme Kookout -destination 'platform=iOS Simulator,name=iPhone 18 Pro' -derivedDataPath build -quiet build
xcrun simctl install booted build/Build/Products/Debug-iphonesimulator/Kookout.app
xcrun simctl launch booted com.sternell.kookout -AppleLanguages "(nb)" -AppleLocale nb_NO
cd relay && npx wrangler deploy
cd relay && npx wrangler d1 execute kookout --remote --command "SELECT …"
```

## Gotchas

- The Bash tool runs zsh: split strings with `${=var}`; Homebrew tools are in `/opt/homebrew/bin` (not always on PATH).
- Command-line builds don't fill `.xcstrings`; find new texts in the build's `.stringsdata` files and add them.
- New Swift files only compile after `xcodegen`.
- `simctl launch` starts the old app unless you `simctl install` first.
- Cloudflare can take a minute to roll out a deploy; retry before assuming code is wrong.
- NOAA's wave server is sometimes down; the relay waits at most 2.5 s (8 s outside MET's waters) and remembers failures.
- MET gives no gusts outside the Nordic countries; the wind rule then uses the mean wind only.
- Holfuy data can only be shown through Holfuy's widget (their API is for station owners).
- SwiftUI: a `.task` or `.sheet` on a view that may be empty, or on a whole List section, may never run; attach it to something that's always there.
- Email for kookout.no: inbound stays at Domeneshop (don't let Resend add MX records); Resend only sends.

## If things break

| Problem | What to do |
|---|---|
| A relay deploy broke something | `cd relay && npx wrangler rollback` (goes back to the previous version) |
| Wrong data in the database | D1 keeps 30 days of history: `npx wrangler d1 time-travel restore kookout --timestamp=<before>` |
| A bad TestFlight build | App Store Connect → TestFlight → the build → Expire Build |
| Web page broken | Revert the commit on GitHub; Actions redeploys |
| Notifications stopped | Check secrets (`npx wrangler secret list`), the APNs key at developer.apple.com, and `npx wrangler tail` |
| Report emails stopped | Resend dashboard → Emails / Domains (kookout.no must stay verified) |
